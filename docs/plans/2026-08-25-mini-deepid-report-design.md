# Mini-DeepID 论文式报告设计

## 定位

报告采用“小论文正文 + 工程复现附录”的组织方式。正文回答研究目的、原论文思想、Mini-DeepID 方法、实验结果和局限；附录保存环境、复现命令和产物索引。全文必须明确：本实验受到香港中文大学团队 CVPR 2014 DeepID 工作启发，复现的是“身份分类驱动判别特征、160D 表示和多尺度互补”的核心思想，而不是原论文 97.45% LFW verification benchmark。

## 结构

1. 摘要与关键词；
2. 研究背景、目的和贡献；
3. 原论文小节与复现边界；
4. 技术方法树与实验流程；
5. 数据集、固定划分和无泄漏协议；
6. 模型结构、前向传播与损失函数公式；
7. 环境、训练策略和分阶段验收；
8. 定量结果、逐类分析、混淆矩阵、预测案例和 PCA；
9. 论点验证、局限、误差来源与改进方向；
10. 结论、可复现性附录和参考文献。

## 图表与证据

Markdown 图片全部使用从 `docs/` 指向 `../outputs/` 的相对路径。方法树使用 Mermaid，数学公式使用 LaTeX。所有数字以 `outputs/*.json`、冻结 manifest 和正式训练历史为依据，不补造未观测结果。核心图包括数据分布、样本网格、Tiny Overfit、正式训练曲线、混淆矩阵、预测样例和 160D PCA。

## 验收标准

- 不出现 TODO 或未替换占位符；
- 77.50% 测试准确率、0.7758 Macro F1、epoch 75 的 80.00% 最佳验证准确率与原始产物一致；
- 明确测试集只有 80 张，结论不能外推到开放集或实际身份认证；
- PCA 明确为 train fit、test transform；
- 图片路径存在，公式和 Mermaid 围栏闭合；
- 给出具体、可执行且不虚构效果的改进方向。
